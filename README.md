# Phần 1: Tại sao hay bị"văng đăng xuất"?Và giải pháp 3 profile
## 1.Nguyên nhân gây văng phiên đăng nhập:
- Dùng chung 1 chỗ:Tất cả mọi người dùng chung một cửa sổ chrome và chung thư mục dữ liệu.
- Xung đột cookie:khi bác sĩ đang mở phần mềm khám bệnh.Thực tập sinh mở tab đăng nhập khác,hệ thống tưởng rằng thay đổi phiên làm việc đột ngột khiến cho máy của bác sĩ bị đăng xuất đột ngột khi đang kê đơn.

## 4. Mẹo "Favicon-Only" (Chỉ hiện biểu tượng)
- Cách làm:Nhấp chuột phải vào trang web trên thanh bookmark->chọn chỉnh sửa->xóa sạch tên->nhấn lưu.
- Lợi ích:tiết kiệm không gian giúp các trang quan trọng nằm gọn không bị tràn màn hình.
